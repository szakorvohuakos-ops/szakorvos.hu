🔄 Google Klinika Import

Magyar magánklinikák importálása a Google Places API-ról

Figyelem: A SERVICE_ROLE_KEY-t bizalmasan kezeld, ez teljes hozzáférést ad a DB-hez. A böngésződ lokálisan tárolja, hogy ne kelljen újra beírnod, de senki másnak ne add meg.

1 Supabase Service Role Key

Megtalálható: Supabase Dashboard → Project Settings → API → service_role secret. Egyszer kell megadnod, utána a böngésződ megjegyzi (localStorage).

2 Import paraméterek

Üresen hagyva a 16 alapértelmezett magyar várost futtatja le.
1-60 között (Google max 60-at ad oldaltémérten).
Text Search ára: $0.032 / hívás (a Google havi $200 ingyenes kredit ad).
